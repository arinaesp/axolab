# axo — Landing Page

Landing page for **axo**, a Telegram Mini App that teaches children English vocabulary through coding commands.

Kids give the hero simple English commands — `jump`, `run`, `hide` — and see the result on screen. Language meets logic in one calm, timer-free game.

## Live

Deployed via GitHub Pages from `main`.

## Features

- Bilingual RU/EN toggle across all pages — content switches without a page reload
- Inline SVG Venn diagram showing axo at the intersection of Coding and English
- Scroll-triggered reveal animations with spring easing
- Mascot float animation with interactive hover
- Responsive — single-column on mobile, expands on desktop
- Respects `prefers-reduced-motion`
- Keyboard-accessible with visible focus states

## Methodology

axo's approach to teaching English through coding is an original methodology created by Arina Bolotbekova, based on hands-on experience working with children. The method builds on TPR (Total Physical Response) — kids learn words by physically acting them out through code commands.
